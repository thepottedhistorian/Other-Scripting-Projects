🌸 Jenny's Orchid Management System — Changelog

Release History & System Architecture Notes

v1.0.0 — Tailored Collection Edition November 13, 2026
  • Consolidated Codebase: Streamlined backend automation into 6 modular scripts (Config.gs, MenuAndNavigation.gs, InventoryAndArchive.gs, EventHandlers.gs, CareAndRepotTools.gs, and FormattingAndDiagnostics.gs) paired with 4 interactive HTML UI templates.
  • Compact A:N Specimen Layout: Standardized individual specimen tabs to a unified horizontal layout featuring Bloom Log (A:D), Notes (F:G), Repotting Log (I:J), and Watering Log (L:N) starting at Row 20.
  • Header Row Protection: Added row-level guards (currentRow <= 2) to Maintenance Log edit triggers to protect column headers from accidental timestamp overwrites.
  • Dynamic Collection Scaling: Removed fixed tab-count limits so all batch formatters, duration audits, and health diagnostics scale automatically as new orchids are added.
  • Archived Age Tracking: Updated Archived Orchids decommissioning logic to compute each specimen's total time in the collection between Acquisition Date and Archived Date.
